# Девять органов человека + Скелет и мышцы

Статический сайт. Новая секция «Скелет и мышцы» (трёхмерный атлас
опорно-двигательного аппарата) добавлена под органами, перед подвалом.

## Что изменилось

- `index.html` — подключены скрипты вьювера (в конце body).
- `style.css` — добавлены стили секции (блок «СКЕЛЕТ И МЫШЦЫ» в конце файла).
- `anatomy/anatomy-viewer.js` — сам вьювер: сцена, подсветка препаратов,
  всплывающие подписи, поиск по русским и латинским названиям, слои
  «Скелет/Мышцы», рентген-режим, автовращение, сброс вида.
- `anatomy/anatomy-parts.js` — названия 667 препаратов (русский + латынь).
- `anatomy/models/skeletal.glb` (2,6 МБ) и `muscular.glb` (10,5 МБ) —
  объединённые модели; каждый препарат — отдельный узел с именем.
- `anatomy/vendor/` — three.js r128, GLTFLoader, OrbitControls, MeshoptDecoder.

Файлы `app.js` и `ui-fixes.js` не менялись. Существующие папки сайта
(`models/` с органами и `atlas/` с иллюстрациями) должны остаться на месте —
на локальной копии без них органы покажут «не удалось загрузить модель».

## Установка

Просто загрузите всё содержимое этой папки в корень сайта ( рядом с уже
лежащими `index.html`, `app.js`, папкой `models/`), сохранив структуру:

```
index.html            (заменить)
style.css             (заменить)
app.js                (без изменений)
ui-fixes.js           (остаётся ваш)
anatomy/…             (новая папка)
models/… atlas/…      (остаются ваши)
```

Модели загружаются лениво — только когда посетитель долистал до секции.
